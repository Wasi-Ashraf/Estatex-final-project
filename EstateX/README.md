# EstateX — Real Estate & Rental Platform

EstateX is a property discovery, buying, and rental platform for houses, apartments, shops, plots, and agricultural land.

## Project Structure
- `frontend/` — React + Vite user interface
- `backend/` — Node.js + Express + MongoDB API
- `DOC/` — project documentation, daily tasks, and weekly modules
- `prototype/` — UI/UX prototypes and design references

## Getting Started
See `frontend/README.md` and `backend/README.md` for setup instructions.

## Development Approach
Follow the documentation in `DOC/`. Complete and verify each task before moving to the next one.
