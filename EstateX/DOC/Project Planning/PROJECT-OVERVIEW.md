# EstateX Project Overview

## Project Name
EstateX — Real Estate & Rental Platform

## Purpose
Provide a platform to discover, buy, and rent residential and commercial properties, plots, and agricultural land.

## Main Roles
- Visitor
- User / Buyer / Renter
- Seller
- Admin

## Core Modules
- Authentication and role-based access
- Property listings and details
- Search and filters
- Seller property management
- Favorites and inquiries
- User and seller dashboards
- Admin moderation
- Testing, SEO, and deployment

## Technology
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB + Mongoose
- Validation: Zod
