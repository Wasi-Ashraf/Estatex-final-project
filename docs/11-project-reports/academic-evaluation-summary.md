## 1. Project Background & Institutional Significance

EstateX has been designed and structured to serve as an exemplary final-year capstone project for the DAE CIT curriculum at GCT Bhakkar. The project demonstrates mastery of modern full-stack web engineering, database architecture, network security, software quality assurance, and professional software development methodologies.

Rather than developing an unstructured application, EstateX adheres to **Spec-Driven Development (SDD)**, utilizing industry-standard tools including **GitHub Spec Kit** and **Google Antigravity**.

---

## 2. Technical Competencies Demonstrated

### 2.1 Software Engineering & Methodology
- Formal requirements engineering (Functional and Non-Functional Requirements).
- Rigorous Spec-Driven Development lifecycle (Constitution, Specify, Clarify, Plan, Checklist, Tasks, Analyze).
- Bidirectional Requirements Traceability Matrix (RTM) linking 100% of features to tests.

### 2.2 System & Database Architecture
- 3-Tier Client-Server decoupled web architecture.
- Document-oriented NoSQL database modeling using MongoDB and Mongoose.
- High-performance database indexing (compound, text, and unique indexes).
- Pakistan-specific localization (Marla/Kanal conversions, PKR formatting).

### 2.3 Web & API Engineering
- RESTful API design standards with predictable JSON response envelopes.
- Single Page Application (SPA) frontend architecture using React.js and Vite.
- Responsive design tailored for mobile, tablet, and desktop viewports.

### 2.4 Application Security & Quality Assurance
- Stateless token authentication using JSON Web Tokens (JWT).
- Industry-standard password hashing using bcrypt (cost factor 10).
- Role-Based Access Control (RBAC) across Buyer, Seller, and Admin tiers.
- Defense-in-depth security mitigations aligned with OWASP Top 10 standards.
- Structured testing strategy spanning Unit, Integration, and E2E test suites.
