# Database Schemas Specification

This folder houses the formal schema definitions for EstateX MongoDB collections:
- `UserSchema`: Identity, roles, password hashes.
- `PropertySchema`: Listings, multi-category specifications, Pakistan location hierarchy, images.
- `InquirySchema`: Buyer lead communication records.
- `FavoriteSchema`: Saved property references with unique compound indexing.

Refer to [Database Schema Design](file:///D:/estatex/docs/06-database/database-schema-design.md) for full field definitions.
