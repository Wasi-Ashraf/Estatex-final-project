# EstateX — Database Architecture & Seed Directory

## Purpose & Scope
This directory contains database schema definitions, seeding fixtures, and migration scripts for the EstateX MongoDB database.

## Folder Organization
- `schemas/` — Mongoose schema specifications and JSON schema definitions.
- `seeders/` — Standard Pakistani property market test fixtures (mock users, verified listings across Bhakkar, Lahore, Islamabad, Multan, and sample inquiries).

## Rules & Development Status
- **Current Status:** Foundation & Architectural Design.
- **Strict Constraint:** No live database connections or active seed scripts are executed until implementation authorization is provided.
