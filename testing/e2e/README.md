# End-to-End (E2E) Testing Specifications

This folder contains end-to-end test scenarios:
- **Journey 1:** Visitor discovers property -> Registers as buyer -> Adds to favorites -> Submits inquiry.
- **Journey 2:** Seller registers -> Publishes house listing -> Admin approves listing -> Seller receives inquiry lead.
- **Journey 3:** Admin reviews pending listings -> Rejects non-compliant listing with feedback.
