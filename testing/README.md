# EstateX — Automated & Integration Test Directory

## Purpose & Scope
This directory houses test scripts, fixtures, Postman collections, and automated test runners for the EstateX platform.

## Folder Organization
- `unit/` — Unit tests for helper utilities, validation schemas, and individual controllers.
- `integration/` — API endpoint tests using Supertest and in-memory MongoDB.
- `e2e/` — End-to-end journey tests covering user registration, property listing, and inquiry submission.

## Execution Status
- **Current Status:** Foundation & Test Plan Stage.
- **Strict Rule:** Test suites will be executed once the application code is authorized for implementation.
