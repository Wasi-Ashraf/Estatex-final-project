# EstateX — Project Management Documentation Index

## Purpose & Scope
This directory contains project governance, task breakdowns, roadmap tracking, and the Requirements Traceability Matrix (RTM).

## Subdirectories
- `roadmap/` — 16-week milestone schedule, deliverable deadlines, and progress logs.
- `traceability/` — Bidirectional Requirements Traceability Matrix (RTM).
- `tasks/` — Module-wise task work breakdown structure (WBS) for implementation.
