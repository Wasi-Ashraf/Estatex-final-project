# EstateX — Frontend Presentation Layer

## Overview
The `frontend/` directory contains the modern React.js Single Page Application (SPA) for EstateX, configured with Vite, standard HTML5 semantic elements, and modern CSS3.

## Architectural Responsibilities
- Render public browsing, listing discovery, and property detail views.
- Provide secure authentication UI (Login, Register, Password validation).
- Provide role-specific dashboards for Buyers, Sellers, and Administrators.
- Implement responsive, mobile-first layouts tailored for Pakistani users across mobile, tablet, and desktop screens.
- Manage client-side routing, protected route guards, and API data synchronization.

See [Frontend Architecture Specification](file:///D:/estatex/docs/04-architecture/frontend-architecture.md) for full details on component hierarchy, routing, context providers, and design tokens.
